# Torn Media Chat

**Torn Media Chat** adds an emoji picker, direct image uploads, and live GIF search right into Torn’s chat boxes on both desktop browsers and the Torn PDA mobile app. Shared images and GIFs render directly inside the chat bubble for script users while staying as normal clickable links for everyone else.

## Installation

1. Install **Tampermonkey** (Desktop) or open **Torn PDA** (Mobile -> Settings -> Advanced Browser Settings -> Userscripts).
2. **[Click here to install Torn Media Chat v1.6](https://raw.githubusercontent.com/YOUR_USERNAME/torn-media-chat/main/torn-media-chat.user.js)**
3. Refresh Torn.

## Features
- **Searchable Emoji Picker:** Browse 1,800+ emojis by category, search by keyword, and access recently used emojis.
- **Direct Image Upload & Paste:** Upload images from your computer or phone gallery, paste screenshots (`Ctrl+V`), or insert image URLs with automatic compression for mobile.
- **Live GIF Search:** Search trending or keyword-matched GIFs via Giphy (click the `🔑` icon in the GIF tab to save a free Giphy API key).
- **Clean Inline Previews:** Displays images and GIFs inside chat with a click-to-zoom lightbox while hiding raw media URLs for script users.
